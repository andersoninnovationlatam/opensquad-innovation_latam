# Checkpoint: Aprovar Conteúdo

O copy do carrossel está pronto!

**Revise os slides acima** antes de avançar para a produção visual (geração de imagens e renderização dos slides).

Responda:
- **"ok"** ou **"aprovar"** para avançar para a produção das imagens
- Qualquer outra resposta para solicitar ajustes no copy

> Após este ponto, o Designer vai gerar as imagens AI de fundo e renderizar todos os slides.
> Ajustes no copy depois deste passo exigem re-renderização dos slides.
