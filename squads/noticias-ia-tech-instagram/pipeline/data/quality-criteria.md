# Critérios de qualidade — squad Notícias IA & tech

## Pesquisa / curadoria

| Critério | Mínimo aceitável |
|----------|------------------|
| Fontes | URL + data por notícia listada |
| Confiança | Marcada (alta/média/baixa) por item |
| Alinhamento ao foco | Cada item justifica relevância ao `research-focus` |

## Copy (legendas + roteiro de slides)

| Critério | Mínimo aceitável |
|----------|------------------|
| Coerência factual | Nada inventado face à notícia escolhida |
| Tom | Profissional/institucional (pt-BR) |
| Formato | Dentro dos limites `instagram-feed` (caption, hashtags, slides) |
| Keywords / hashtags | Lista explícita; 5–15 hashtags recomendadas |

## Verificação (designer)

| Critério | Mínimo aceitável |
|----------|------------------|
| `verification-news.md` | Resultado PASS ou FAIL documentado |
| Em FAIL | Não prosseguir para geração de imagens até correção |

## Visual (carrossel)

| Critério | Mínimo aceitável |
|----------|------------------|
| Proporção | 1080×1440 (3:4) por slide |
| Legibilidade | Hierarquia título + apoio; contraste suficiente |
| Créditos | Fonte citada no último slide ou em manifest |
| Tipografia | Máximo 2 famílias; preferência Montserrat Bold + Open Sans |
| Tamanho mínimo | Título ≥ 80 px · Corpo ≥ 32 px · Caption ≥ 24 px |
| Contraste | WCAG AA: ≥ 4.5:1 para corpo; ≥ 3:1 para títulos grandes |
| Paleta | Fundo `#191d24` ou imagem com overlay; texto `#FFFFFF`/`#D0D0D0`; acento `#76cecb` ou `#FFD600` |
| Margens | Mínimo 80 px em todas as bordas |
| Densidade | 1 ideia por slide; máx. 3 linhas de texto de apoio |
| Hierarquia | Título > destaque > apoio visualmente distinguíveis |
| Consistência | Mesma fonte, paleta e layout em todos os slides |
| Mobile-ready | Zoom não necessário para ler qualquer elemento |
| Fundo com imagem | Overlay escuro presente (rgba 50–70% ou gradiente) |

## Revisão final

| Critério | Veredito |
|----------|----------|
| Média ≥ 7/10 e nenhum critério abaixo de 4/10 | APPROVE |
| Caso contrário | REJECT (com feedback acionável) |
