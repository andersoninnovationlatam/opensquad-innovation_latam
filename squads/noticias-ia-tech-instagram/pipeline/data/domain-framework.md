# Domain framework — Notícias IA & tech → Instagram feed

## Fluxo editorial (alto nível)

1. **Foco do dia** — O gestor define tema e janela temporal (`research-focus.md`).
2. **Curadoria** — Pesquisa em fontes públicas; ranqueamento por credibilidade, frescor e relevância para público misto (clientes, leads, geral).
3. **Escolha de uma notícia** — Uma só história para desenvolver (evita dispersão).
4. **Ângulos** — Cinco perspetivas distintas sobre **a mesma** notícia; escolha de um ângulo.
5. **Copy Instagram** — Legenda + roteiro de carrossel (slides) com keywords e hashtags; tom profissional/institucional.
6. **Aprovação de texto** — Gate antes de qualquer pixel final.
7. **Verificação visual** — Designer confirura fatos e URL contra copy aprovado.
8. **Carrossel profissional** — Slides 3:4, hierarquia tipográfica, créditos de fonte.
9. **Revisão** — Veredito APPROVE/REJECT; entrega para publicação manual.

## Princípios

- Uma notícia por execução até ao carrossel final.
- Precisão antes de criatividade visual.
- Publicação fora do pipeline (manual pelo gestor).
