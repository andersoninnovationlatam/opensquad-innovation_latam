# Output Examples: Tech Instagram Carousel

## Example 1: Educational Tutorial Carousel

**Topic:** "Como usar IA para programar 3x mais rápido"

**Selected Angle:** Educacional (actionable knowledge)

**Format:** Tutorial / Passo-a-passo

### Slides Structure

**Slide 1 (Cover):**
- Title: Como usar IA para programar 3x mais rápido
- Subtitle: guia prático testado por 3 meses
- Background: Dark gradient with code overlay
- Visual: Bold typography with accent color

**Slide 2 (Context):**
- Headline: Desenvolvedores que usam IA economizam 18 horas por semana
- Supporting text: Pesquisa da GitHub (2026) com 10 mil devs mostra que assistentes de IA reduziram tempo em tarefas repetitivas em 67%. Mas poucos sabem usar direito.
- Accent keywords: "18 horas", "67%"
- Background: Dark

**Slide 3 (Passo 1):**
- Headline: 1. Escolha a ferramenta certa para cada tipo de tarefa
- Supporting text: GitHub Copilot para autocompletar código. Claude/ChatGPT para arquitetura e debugging. Cursor para refactoring completo. Não existe "melhor ferramenta" — existe ferramenta certa para o momento.
- Accent keywords: "ferramenta certa"
- Background: Light card on dark

**Slide 4 (Passo 2):**
- Headline: 2. Comece com tarefas repetitivas antes de arquitetura
- Supporting text: IA economiza 80% do tempo em boilerplate, testes unitários, documentação. Arquitetura complexa ainda precisa de humano. Delega o que consome tempo mas não exige decisão crítica.
- Background: Dark

**Slide 5 (Passo 3):**
- Headline: 3. Aprenda a escrever prompts como você escreve specs
- Supporting text: "Crie uma função" é vago. "Crie função validateEmail que aceita string, retorna boolean, valida formato RFC 5322" gera código pronto. Quanto mais específico o prompt, menos revisão depois.
- Background: Accent card

**Slide 6 (Passo 4):**
- Headline: 4. Revise linha por linha — IA erra em edge cases
- Supporting text: 34% do código gerado por IA tem bugs sutis (pesquisa MIT 2026). Sempre teste com inputs extremos: strings vazias, números negativos, arrays gigantes. IA é assistente, não substituto.
- Background: Dark

**Slide 7 (Passo 5):**
- Headline: 5. Mede o impacto real no seu workflow
- Supporting text: Track quanto tempo você leva em cada tarefa por 1 semana. Identifica onde IA economiza mais tempo. Ajusta o uso baseado em dados reais, não hype.
- Background: Light card

**Slide 8 (Synthesis):**
- Headline: O resultado depois de 3 meses
- Supporting text: Refactoring que levava 4 horas agora leva 45 minutos. Documentação que levava 2 horas leva 20 minutos. Não é mágica. É método aplicado consistentemente.
- Background: Dark with stat overlay

**Slide 9 (CTA):**
- Headline: Comece com uma ferramenta hoje
- Supporting text: Teste o GitHub Copilot ou Cursor esta semana. Mede quanto tempo você economiza. Ajusta conforme seu workflow.
- CTA: "Comenta 'GUIA' que eu mando o checklist completo de IA para devs"
- Background: Accent

### Caption

```
A maioria dos desenvolvedores está usando IA errado.

Eu passei 3 meses testando todos os assistentes de código. Descobri que não é sobre qual ferramenta você usa. É sobre COMO você usa.

Swipe pra ver o framework completo →

O que mudou pra mim: antes eu levava 4 horas pra refatorar um módulo. Hoje levo 45 minutos. Não é mágica. É método.

Qual assistente de IA você usa? Comenta abaixo.

[Disclaimer: Conteúdo criado com assistência de IA]
```

## Example 2: Contrarian Myth-Busting Carousel

**Topic:** "Por que usar MUITA IA pode estar te atrasando"

**Selected Angle:** Contrário (challenges conventional wisdom)

**Format:** Mito vs Realidade

### Slides Structure

**Slide 1 (Cover):**
- Title: 5 mitos sobre IA que estão te atrasando
- Subtitle: Harvard acabou de publicar pesquisa polêmica
- Background: Bold red/black split
- Visual: Contrarian visual language

**Slide 2 (Mito 1):**
- Headline: MITO: Quanto mais IA, melhor
- Supporting text: REALIDADE: Harvard publicou estudo mostrando que usar mais de 3 ferramentas de IA simultaneamente causa "brain fry" — fadiga cognitiva severa. O ideal é 2-3 ferramentas bem dominadas.
- Accent keywords: "brain fry", "2-3 ferramentas"
- Background: Dark with red accent

**Slide 3 (Mito 2):**
- Headline: MITO: IA é sempre mais rápida que humano
- Supporting text: REALIDADE: Para tarefas criativas e estratégicas, IA pode desacelerar. MIT mostrou que brainstorming assistido por IA gerou 40% menos ideias inovadoras. IA acelera execução, não pensamento original.
- Background: Light card with red accent

**Slide 4 (Mito 3):**
- Headline: MITO: Você precisa usar IA em tudo
- Supporting text: REALIDADE: 68% dos early adopters reportam "automation fatigue" — cansaço de gerenciar múltiplas IAs. Use onde há ROI claro: tarefas repetitivas, pesquisa inicial, rascunho de texto. Ignore o resto.
- Background: Dark

**Slide 5 (Mito 4):**
- Headline: MITO: IA substitui necessidade de aprender
- Supporting text: REALIDADE: Desenvolvedores que usam IA sem entender o código base cometem 3x mais erros de arquitetura (Stack Overflow 2026). IA é multiplicador de conhecimento, não substituto.
- Background: Red accent card

**Slide 6 (Mito 5):**
- Headline: MITO: Todo mundo está usando IA com sucesso
- Supporting text: REALIDADE: 71% dos usuários de ferramentas de IA reportam frustração com outputs genéricos. A maioria não sabe escrever prompts eficazes. O problema não é a ferramenta — é o método.
- Background: Dark

**Slide 7 (Synthesis):**
- Headline: O que funciona de verdade
- Supporting text: Use 2-3 ferramentas bem. Foca em tarefas com ROI claro. Continua estudando fundamentos. Trata IA como assistente qualificado, não mágica.
- Background: Light card

**Slide 8 (CTA):**
- Headline: Qual mito te surpreendeu mais?
- Supporting text: Comenta o número do mito (1-5). Se quiser o paper completo da Harvard, comenta "PAPER".
- Background: Red accent

### Caption

```
Você está usando IA pra TUDO. E isso pode ser um problema.

Nova pesquisa da Harvard descobriu que existe um limite. Passou dele, a produtividade cai. O cérebro entra em fadiga cognitiva.

Os 5 mitos que ninguém tá falando →

Spoiler do mito #3: você provavelmente está automatizando coisas que não deveria.
```

## Example 3: Listicle Feature Breakdown

**Topic:** "5 recursos do ChatGPT que você não conhece"

**Selected Angle:** Oportunidade (competitive advantage)

**Format:** Listicle

### Slides Structure

**Slide 1 (Cover):**
- Title: 5 recursos do ChatGPT que até especialistas ignoram
- Subtitle: testei todos durante 2 semanas
- Background: Dark with ChatGPT green accent

**Slide 2 (Recurso 1):**
- Headline: 1. Custom Instructions que persistem entre conversas
- Supporting text: 90% dos usuários não sabem que podem salvar contexto permanente. Configure uma vez (seu role, estilo de output preferido, restrições). ChatGPT lembra em TODAS as conversas futuras.
- Accent keywords: "contexto permanente", "lembra"
- Background: Dark

**Slide 3 (Recurso 2):**
- Headline: 2. Code Interpreter para análise de dados sem código
- Supporting text: Upload CSV, pede análise, ChatGPT roda Python e gera gráficos automaticamente. Não precisa saber programar. Economiza 4+ horas de trabalho manual.
- Background: Light card

**Slide 4 (Recurso 3):**
- Headline: 3. Browse with Bing para pesquisa em tempo real
- Supporting text: ChatGPT só sabe até 2023? Ative Browse mode e ele busca info atual na web. Ideal para notícias, dados atualizados, verificação de fatos recentes.
- Background: Dark with accent

**Slide 5 (Recurso 4):**
- Headline: 4. Prompt templates que você pode salvar e reusar
- Supporting text: Cria prompts complexos uma vez, salva como template, reutiliza com um clique. Perfeito para tarefas repetitivas (emails, relatórios, análises).
- Background: Light card

**Slide 6 (Recurso 5):**
- Headline: 5. Voice mode que entende contexto de conversa
- Supporting text: Não é só speech-to-text. Voice mode mantém contexto, interrompe quando você fala, ajusta resposta baseado em tom de voz. É como ter assistente real no ouvido.
- Background: Dark

**Slide 7 (Impact):**
- Headline: O que mudou quando comecei a usar tudo
- Supporting text: Tempo de pesquisa caiu 60%. Qualidade de outputs subiu visivelmente (custom instructions eliminaram 90% das correções). Produtividade dobrou em tarefas repetitivas.
- Background: Accent card with stat

**Slide 8 (CTA):**
- Headline: Qual você vai testar primeiro?
- Supporting text: Comenta o número (1-5). Se quiser tutorial completo de cada recurso, comenta "TUTORIAL".
- Background: Dark

### Caption

```
5 recursos do ChatGPT que até especialistas ignoram.

Eu uso ChatGPT todo dia faz 1 ano. Semana passada descobri que estava usando só 40% da capacidade.

Esses 5 recursos mudaram completamente meu workflow →

O recurso #4 sozinho me economiza 2 horas por semana. E 90% das pessoas não sabe que existe.

Qual você vai testar primeiro? Comenta o número.
```
